# Sample Incharge Dashboard — Local Prototype

A standalone-in-the-client React dashboard component for the Government FMS project.

## Folder
`client/src/features/admin/sample-incharge/`

## Included
- Overview and stock summary
- Sample register and CSV export
- Receive and issue stock movements with balance checks
- Movement history
- Draft request workflow placeholder
- Basic reports, low-stock notifications and settings
- Responsive layout and local demo data

## Local behavior
This component uses React state only. Sample records and stock movements reset on refresh. It has no backend integration or authentication of its own. The parent application route controls access.

## Integration reminder
Confirm the real sample-management domain, stock thresholds, units, expiry rules, approval process and role permissions with the team before using real records. All data included is illustrative demo data.
