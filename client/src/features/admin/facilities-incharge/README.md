# Facilities Incharge Dashboard — Local Prototype

Folder in the existing client: `client/src/features/admin/facilities-incharge/`

Includes overview, facilities register, work orders, maintenance schedule, inspection checklist, service-provider placeholder, reports, notifications, settings, CSV export and responsive layout.

All records are illustrative demo data. Changes are held in React state and reset on refresh. This component has no API/database integration; the parent router controls access.

Confirm facility categories, priority definitions, maintenance recurrence, inspection requirements, vendors, approvals and permissions with the team before using real records.
